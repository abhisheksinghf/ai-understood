## 1. Read an equation as a calculation

**Algebra** uses symbols to describe relationships. A **variable** stands for a value; a **function** maps an input to an output. In the familiar toy predictor:

$$
f(x)=wx+b
$$

x is the input, w is its weight, and b is the **bias** or intercept. With w = 2 and b = 1, entering x = 3 gives 2 × 3 + 1 = 7. Multiplication happens before addition. The function is not learned merely because we have written it as an equation.

If you know an output y and w is nonzero, subtract b from both sides and divide by w:

$$
y=wx+b\quad\Longrightarrow\quad x=\frac{y-b}{w}
$$

For y = 7, this gives x = (7 − 1) / 2 = 3. When w = 0, every input returns b, so the output cannot identify a unique input.

Strictly, multiplication by w is **linear**; adding a nonzero b makes the map **affine**. A linear map preserves addition and scaling and sends zero to zero. The familiar “linear regression” model usually includes an intercept despite that name.

<details className="optional-depth">
<summary>Math refresher: powers, roots, logarithms, and subscripts</summary>

A power repeats multiplication: 2³ = 2 × 2 × 2 = 8. The nonnegative square root reverses squaring a nonnegative number: √9 = 3, while (−3)² is also 9. Parentheses matter. In Python, use <code>**</code> for a power; <code>^</code> is not exponentiation.

A logarithm asks for the exponent: log₂(8) = 3 because 2³ = 8. Real logarithms require a positive argument and a positive base other than 1. The natural logarithm uses the base e, approximately 2.718. We will use logs in later probability and loss calculations.

Subscripts identify entries: x₁ means the first entry, not x multiplied by 1. A hat, as in ŷ, means a prediction. Mathematical indices often start at 1; Python list indices start at 0.

</details>

## 2. Know what object each symbol represents

**Linear algebra** studies vectors, matrices, and linear maps. Keep the type of numerical object separate from its values:

| Object | Meaning here | Example shape |
|---|---|---|
| Scalar | One number, such as a bias | No array axes |
| Vector | An ordered collection of coordinates | 2 entries |
| Matrix | A rectangular array, indexed by row and column | 3 × 2: three rows, two columns |
| Tensor in an ML library | An array that can have multiple axes | 8 × 32 × 64: three axes |

The **shape** records the size of each axis. A vector with two coordinates belongs to a two-dimensional space; that does not mean a library must store it as a two-axis array. A column representation has shape 2 × 1, whereas a NumPy one-dimensional array has shape <code>(2,)</code>.

<AlgebraDiagrams kind="shapes" />

For this chapter, let **x = [3, 2]** locate a point: **3 units horizontally and 2 vertically**. These are dimensionless geometric coordinates. Coordinate order is part of the contract; swapping the entries moves the point even though its shape stays the same. In ML, vector entries can instead represent named features.

A batch of 8 sequences, each with 32 positions and 64 numerical features, can be stored as an 8 × 32 × 64 tensor. Name the axes before doing arithmetic. The [D2L linear algebra introduction](https://d2l.ai/chapter_preliminaries/linear-algebra.html) gives more examples of these objects.

## 3. Add, scale, and measure a vector

For geometry, use dimensionless coordinates **u = [3, 4]** and **v = [1, −1]**, in the same geometric plane. Add corresponding entries: u + v = [4, 3]. Multiply every entry to scale: 2u = [6, 8]. A negative scalar reverses direction; multiplying by zero produces the zero vector.

A **linear combination** scales vectors and adds them. For example, 2u + v = [7, 7]. Geometrically, place arrows head to tail to add them.

<AlgebraDiagrams kind="vectors" />

The **Euclidean norm**, written with double bars, measures length:

$$
\|\mathbf{u}\|_2=\sqrt{3^2+4^2}=5
$$

The **Euclidean distance** between two vectors is the length of their difference. Here u − v = [2, 5], so their distance is √29, approximately 5.385. Length is a distance from zero; distance between two vectors need not equal either vector's length.

For nonzero u, dividing by its norm creates a **unit vector**: u / 5 = [0.6, 0.8], of length 1. This preserves direction while removing magnitude. The zero vector cannot be normalized this way.

<details className="optional-depth">
<summary>Go deeper: norms and feature scaling</summary>

The L1 norm adds absolute values: for [3, −4], it is 7. The L2 norm is √(9 + 16) = 5. The infinity norm takes the largest absolute entry: 4. These measure size in different ways and appear in distance measures and regularization.

Do not blindly measure distance between raw features with different units. For example, a house-area coordinate measured in square feet can dominate a bedroom count. Feature scaling uses a stated convention to make comparisons appropriate; fit any learned scaling statistics on training data, then reuse them for validation and test data.

Unit-length normalization acts on a vector's magnitude. Standardizing a feature using its mean and standard deviation is a different operation, introduced with statistics next chapter.

</details>

## 4. Use a dot product to combine evidence

The **dot product** multiplies corresponding coordinates and sums the results. It produces one scalar, not another vector. With coordinates x = [3, 2], weights w = [2, 0.5], and bias b = 1:

$$
\hat{y}=\mathbf{w}^{\mathsf T}\mathbf{x}+b
=2\times3+0.5\times2+1=8
$$

Read the contributions separately: twice the horizontal coordinate gives 6; half the vertical coordinate gives 1; the intercept adds 1. This affine map assigns the point the scalar output 8. All values are dimensionless. The same weighted-sum operation combines features in a prediction model, where units and feature meanings must also match.

The superscript T means **transpose**. It turns the column-vector representation of w into a row, so a 1 × 2 row can multiply a 2 × 1 column. We also write the same operation as w · x.

For d coordinates, the compact notation is:

$$
\mathbf{w}\cdot\mathbf{x}=\sum_{j=1}^{d}w_jx_j
$$

The large sigma means “add these terms for j from 1 through d.” For d = 2, it expands to w₁x₁ + w₂x₂. Matching lengths are necessary, but matching feature order and meaning are just as important.

An **elementwise product** keeps the individual products: [3, 2] multiplied entry by entry by [2, 0.5] gives [6, 1]. The dot product adds those values to get 7; the bias is a separate addition.

## 5. Separate direction from magnitude

For nonzero real vectors, the dot product also relates length and angle:

$$
\cos(\theta)=\frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|_2\|\mathbf{v}\|_2}
$$

Here θ is the angle between the vectors. This ratio is **cosine similarity**. Consider dimensionless vectors:

| Pair | Dot product | Cosine similarity | Interpretation |
|---|---|---|---|
| [3, 4] and [6, 8] | 50 | 1 | Same direction; second vector is twice as long |
| [3, 4] and [−4, 3] | 0 | 0 | Perpendicular, or orthogonal |
| [3, 4] and [−3, −4] | −25 | −1 | Opposite directions |

For the first row, the lengths are 5 and 10, so 50 / (5 × 10) = 1. Its Euclidean distance is 5 even though its cosine similarity is 1. The two measures answer different questions.

Cosine similarity ranges from −1 to 1; it is not a probability. With a zero vector, its denominator is zero and the mathematical value is undefined. A library's fallback value must not be mistaken for a meaningful angle.

Later, embeddings will represent documents as vectors. Similarity is useful only relative to the representation and task: geometrically close vectors do not, by themselves, establish factual agreement or answer correctness.

## 6. Turn a batch into a matrix calculation

Put one example in each row of a **design matrix** X. Here its two columns contain horizontal and vertical coordinates:

$$
X=\begin{bmatrix}1&0\\2&1\\3&2\end{bmatrix},\qquad
\mathbf{w}=\begin{bmatrix}2\\0.5\end{bmatrix},\qquad b=1
$$

X has shape 3 × 2; w has shape 2 × 1. Matrix-vector multiplication takes a dot product with each row:

$$
X\mathbf{w}=\begin{bmatrix}2\\4.5\\7\end{bmatrix},\qquad
\hat{\mathbf{y}}=X\mathbf{w}+b\mathbf{1}
=\begin{bmatrix}3\\5.5\\8\end{bmatrix}
$$

The vector **1** contains three ones, so b is added to every prediction. The general multiplication rule is **(m × n)(n × p) → (m × p)**: inner dimensions match; outer dimensions describe the result. Each output entry is one row-column dot product.

<AlgebraDiagrams kind="product" />

The transpose Xᵀ has shape 2 × 3: rows become columns, without changing the entries' values. Transpose is not inversion. Reversing multiplication is generally different: AB may differ from BA, or one order may not be defined.

In NumPy, <code>@</code> performs matrix multiplication and <code>*</code> performs elementwise multiplication. Plain Python lists do not implement matrix multiplication. See [NumPy's matmul rules](https://numpy.org/doc/stable/reference/generated/numpy.matmul.html).

<details className="optional-depth">
<summary>Go deeper: broadcasting and shape bugs</summary>

**Broadcasting** lets an array operation reuse values across compatible axes. A scalar bias can be added across a prediction array without manually copying it. NumPy compares shapes from the last axis backwards: dimensions must be equal or one of them must be 1; missing leading axes act like size 1.

Beware: an array with shape <code>(3, 1)</code> minus one with shape <code>(3,)</code> produces a <code>(3, 3)</code> array, not three pairwise errors. Explicitly align the shapes of predictions and targets before computing a loss.

A one-dimensional NumPy array with shape <code>(2,)</code> does not become a column when transposed; it stays one-dimensional. Use an explicit 2 × 1 representation when that distinction matters. See [the broadcasting guide](https://numpy.org/doc/stable/user/basics.broadcasting.html).

</details>

## 7. See a matrix change a vector

A matrix can represent a **linear transformation**. Its columns show where the coordinate basis vectors go. In two dimensions, those basis vectors are [1, 0] and [0, 1]. If u = [2, 1], then Au is twice A's first column plus once its second column.

Try the projection with inputs [2, 1] and [2, −3]. Both produce [2, 0]. Their original second coordinates have been discarded. In contrast, a rotation preserves lengths and can be undone by rotating back.

The experiment uses **column vectors**, with A on the left. For batches stored as rows, a library may use a different placement or transpose. Check the stated convention before copying a formula.

## 8. Understand independence and lost information

The **span** of some vectors is everything you can form from their linear combinations. Vectors are **linearly independent** if none adds a redundant direction expressible using the others. A **basis** is an independent collection that spans the space you are describing.

The standard basis [1, 0], [0, 1] spans the whole plane. The pair [1, 0], [2, 0] spans only the horizontal line. A matrix's **rank** is the number of independent columns, also equal to the number of independent rows. Identity has rank 2 here; the projection has rank 1. This meaning of rank differs from “number of tensor axes.”

The **identity matrix** I leaves every vector unchanged. An **inverse** A⁻¹, when it exists, reverses a square matrix: A⁻¹A = I. A square matrix is invertible exactly when it has full rank. Our projection is **singular**, meaning not invertible; no unique inverse can recover its discarded coordinate.

For a 2 × 2 matrix, the **determinant** is ad − bc:

$$
\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc
$$

Its absolute value is the area scale factor; its sign indicates whether orientation flips. The horizontal stretch has determinant 2, the quarter-turn rotation has determinant 1, and the projection has determinant 0. Zero means a square matrix loses at least one independent direction. A determinant is not defined for a rectangular matrix.

<details className="optional-depth">
<summary>Go deeper: solve equations, least squares, and conditioning</summary>

A system A z = t asks for unknown coordinates z. For p + q = 3 and 2p − q = 0, add the equations to get 3p = 3, hence p = 1 and q = 2. Substituting back verifies both equations. The coefficient matrix has rows [1, 1] and [2, −1]; its determinant is −3, so the solution is unique.

Dependent equations can have infinitely many solutions or none: p + q = 3 and 2p + 2q = 6 agree but do not fix p and q separately. Replace the final 6 with 7 and they conflict.

Real data often gives more equations than unknown weights, with no exact fit. **Least squares** chooses weights minimizing the sum of squared residuals, the differences between fitted and observed values. It can be viewed as projecting the target onto the span of the design matrix's columns. We revisit fitting with regression.

Do not assume that explicitly computing a matrix inverse is the best way to solve a system. Numerical solvers and least-squares routines avoid unnecessary inversion. An **ill-conditioned** problem is sensitive to small changes in inputs or rounding; invertible does not mean numerically easy. See [NumPy's least-squares interface](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html).

</details>

<details className="optional-depth">
<summary>Go deeper: eigenvectors, singular values, and compression</summary>

A nonzero **eigenvector** of a square matrix satisfies Av = λv: the output stays on the same line, scaled by its **eigenvalue** λ. A negative λ reverses direction; zero collapses that vector. For the horizontal stretch, [1, 0] has eigenvalue 2 and [0, 1] has eigenvalue 1. Not every real matrix has a complete basis of real eigenvectors.

**Singular value decomposition (SVD)** factors a real matrix as A = UΣVᵀ. The orthogonal factors U and V preserve Euclidean geometry; Σ contains nonnegative singular values that describe stretching along selected directions. This works for rectangular matrices too. Keeping only the largest singular values gives a lower-rank approximation: useful for compression, with information loss.

For the stretch matrix diag(2, 1), the singular values are 2 and 1. Keeping only 2 gives diag(2, 0), which discards the vertical component. For mean-centered data, **PCA** chooses directions of greatest variance; SVD provides a way to compute them. We will study variance and PCA in their own chapters. See [NumPy's SVD reference](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html).

</details>

## 9. Put the calculation into Python

You can implement the essential arithmetic without a numerical library:

```python
def dot(a, b):
    if len(a) != len(b):
        raise ValueError("Vector lengths must match.")
    return sum(left * right for left, right in zip(a, b))

features = [[1, 0], [2, 1], [3, 2]]
weights = [2, 0.5]
bias = 1
predictions = [dot(row, weights) + bias for row in features]
print(predictions)  # [3.0, 5.5, 8.0]
```

<code>zip</code> pairs corresponding entries. Its normal behavior stops at the shorter input, which is why the length check matters. The comprehension calculates one prediction per row; no parameter update occurs.

<details className="optional-depth">
<summary>Connect the shapes to a neural-network layer</summary>

Suppose X contains m examples and d input features. A weight matrix W of shape d × h maps each row to h outputs, giving XW of shape m × h. Add a bias vector with h entries across the rows. An activation function then changes the outputs, usually nonlinearly; we will explain those functions in the neural-network chapter.

For m = 3, d = 2, h = 4, the shape calculation is (3 × 2)(2 × 4) → (3 × 4). Four output features do not create four new independent input directions through a linear map: rank cannot exceed the input rank. This is also why merely stacking affine layers without a nonlinear activation can be combined into one affine map.

</details>

## 12. Keep the meaning beside the mathematics

Before trusting a numerical result, name the axes, check the shape, identify the operation, and explain the units. Then ask what it establishes: a calculation can be mathematically correct while its features, model assumptions, or real-world predictions are wrong.
